# Risks

&emsp;&emsp;Blockchain has high-risk characteristics, and users need to be aware of this.

&emsp;&emsp;There exist a number of potential risks when using zerrow protocols. 
## Smart Contract Security 
&emsp;&emsp;There is an inherent risk that zerrow  could contain a smart contract vulnerability or bug. The zerrow  code is open-sourced, audited (The project has passed audits of octane), and covered by an extensive bug bounty program to minimise this risk.
## 0g Network - Technical Risk 
&emsp;&emsp;Zerrow  is built on 0g and there is no guarantee that 0g network has been developed error-free. Any vulnerabilities inherent to 0g's network brings with it slashing risk.
